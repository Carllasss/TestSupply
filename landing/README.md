# Лендинг

Портфолио-лендинг под вакансию AI Generalist / AI Automation Specialist (Goulash.tech).
React + Vite, стилистика и компоненты (карточки, сетка, плавный скролл) взяты с сайта goulash.tech.

## Запуск

```
npm install
npm run dev
```

## Сборка

```
npm run build
npm run preview
```

Контент резюме — `src/data/content.js`.
